# 개인 랜딩 시안

`index.html`과 `landing.js`로 개인 SaaS 랜딩의 화면과 동작을 검토한다. 기존 문서형 개인 메인은 `preview/`에 남는다. PC 화면 비율을 검토하기 위해 viewport는 기존 PC 검토 폭을 유지한다.

동료 평가 네 개는 레이아웃을 보기 위해 작성한 합성 문장이다. 작성자를 A~D로 표기하고 카드와 상세 창에 예시임을 밝힌다. 실제 인터뷰나 동료의 말을 인용하지 않는다. 미디어 세 개는 기존 base의 배경·강조 색으로 만든 6초 추상 모션 샘플이며 실제 출연 영상이 아니다. 로컬 MP4로 제공하므로 외부 영상 서비스에 의존하지 않는다.

각 띠는 왼쪽으로 반복 이동한다. 마우스와 키보드 초점, 개별 정지, 전체 정지, 화면 밖, 비활성 탭, 대화상자에서 이동을 멈춘다. 화면에 보이는 영상만 음소거 반복 재생한다. 모션 감소 환경에서는 자동 이동과 재생을 하지 않는다. 복제 카드는 키보드와 접근성 트리에서 제외한다. 이전·다음 버튼으로 원본 카드를 이동해 선택할 수 있다.

스타일 정본은 design-tokens의 base다. 새 토큰 값 없이 기존 역할 토큰과 파생식을 사용한다. 공개 출력은 `scripts/build-preview.mjs`의 명시한 파일 목록으로 제한한다.

메인은 소개·동료 평가·출연 영상만 두는 입구다. 프로젝트·블로그·위키 상세는 기존 페이지로 이동한다. 메인에서 상세 목록을 반복하지 않는다.
